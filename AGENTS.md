# Internity - an internship management system

## Tech Stack

### Frontend
  - Tanstack Start 
  - Tanstack Router
  - Zustand
  - Shadcn UI with BaseUI premitives
  - Phosphor Icons - Dualtone 
  - Manrope Font
### Backend
  - Hono JS
  - MongoDB with Mongoose
  - Zod

## Guidelines
  - Always use pnpm as the package manager
  - Set up pnpm to install dependencies that are one week behind to avoid any type of supply chain attacks
  - Both backend and frontend should have different docker images and different configs (Implement when we will be doing CI/CD)

## UI/UX rules
  - Always use .agents/skills/better-ui/ and .agents/skills/emil-design-eng skills for UI/UX design
  - Always use .agents/skills/better-writing for writing 
  - Always try to use beUI components and use .agents/skills/beUI skill
